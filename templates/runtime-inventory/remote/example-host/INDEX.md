# Remote Runtime Inventory

Use this inventory for durable runtime facts discovered on or through this remote host.

```text
remote/example-host/
├── INDEX.md
├── command.md
├── file.md
├── web.md
├── service.md
├── remote/
├── cache/
└── archive/
```

Remote inventories follow the same schema as global and project inventories. Create only the files and directories that are needed in real runtime data.
